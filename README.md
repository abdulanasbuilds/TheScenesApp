# The Scenes

The Scenes is an African-first, globally expandable platform for learning, teaching, community, discovery, and creator-led education.

## Current state

This repository is intentionally starting from a clean application workspace.

The product is currently in the governance + design-first stage.

The next product implementation stage is to generate and compare multiple complete frontend directions before production backend integration.

## Core stack direction

- TanStack Start
- React
- TypeScript
- TanStack Router
- Tailwind CSS
- Radix/shadcn-style primitives

Provider choices are documented but deliberately gated by phase.
