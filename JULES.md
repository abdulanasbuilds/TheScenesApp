# Jules — The Scenes

Read `AGENTS.md` first.

Jules may inspect, implement, test, and review bounded tasks inside the current phase.

Before implementation:
- identify the phase;
- inspect target files;
- confirm in-scope/out-of-scope boundaries;
- use the current design contract.

Before handoff:
- verify;
- inspect the diff;
- record known gaps;
- update durable documentation where needed.
